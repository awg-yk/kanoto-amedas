# Kanto AMeDAS Player

関東平野のアメダス観測データを1時間ごとに再生する VS Code 拡張機能。

- 気温: 地点の丸の色 (-10℃ 青 〜 35℃ 赤)
- 風向風速: 矢印 (風の吹いていく向き、長さ=風速、静穏は小さな○)

## 使い方
1. VS Code でこのフォルダを開き `F5` (Run Extension)
2. コマンドパレットで「Amedas: 関東アメダスプレイヤーを開く」

## データ
- `data/*.csv` (気象庁「過去の気象データ」形式)を全て読み込みます。別フォルダは設定 `kantoAmedas.dataDir` で指定。
- 地点座標は `data/stations.json` (**概算値**。正確な値は気象庁 amedastable.json 等で差し替えてください)。
- テスト: `npm test`

## 2000〜2025年への拡張メモ
現状は全CSVを起動時に読み込みます。26年分(約22万時刻×85地点)ではメモリ・転送量が大きいので、
日付範囲ごとに拡張ホスト側で読み込みwebviewへ送る方式に変える必要があります。
